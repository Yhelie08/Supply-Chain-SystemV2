# PR.READY

> A PR becomes Ready for PO by itself when four conditions pass: supplier selected, final price confirmed, shipping mode selected (Local needs none) and a target date. It goes back to For Sourcing if one stops passing.

**Kind:** AUTOMATIC · **Module:** Purchase Request
