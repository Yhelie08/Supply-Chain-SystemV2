# PR.RECOMMEND

> The recommended supplier is the eligible one with the lowest price (Negotiated if entered, else Initial), with lead time breaking a tie. A supplier that has not quoted is never recommended.

**Kind:** REFERENCE · **Module:** Purchase Request
