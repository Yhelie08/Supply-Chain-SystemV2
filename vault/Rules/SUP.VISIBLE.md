# SUP.VISIBLE

> A supplier sees a PO only once it is sent, and a shipment only once the PO is acknowledged (or the replacement approved). The supplier status of an inquiry or PR line is worked out from the quotes, never stored.

**Kind:** REFERENCE · **Module:** Supplier Portal
